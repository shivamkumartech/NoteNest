# NoteNest - Frontend Client 🎨

This directory contains the React frontend codebase for **NoteNest**, built using Vite, React 19, and Tailwind CSS v4.

For the full setup instructions, system architecture, API schemas, and details on how to run both the client and server, please refer to the main **[Root README.md](../README.md)**.

## 🛠️ Tech Stack & Highlights

- **Vite & React 19:** Instant hot module replacement (HMR) and modern hook implementations.
- **Tailwind CSS v4:** Styled using the latest Tailwind CSS compiler for fast rendering and minimal bundle size.
- **React Context API:** Global notes state management is managed at `src/context/NoteContext.jsx`.
- **Lucide Icons:** Modern and clean svg icon pack.
- **Oxlint:** Lightning-fast JS static analysis.

## 🚀 Commands

Inside this directory, you can run:

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run fast code linting
npm run lint
```
